# Documentation

What this folder holds.

- [`concept.md`](concept.md): why the plugin exists, what it is for, and what it will never do.
- [`architecture.md`](architecture.md): how it is built. The eleven Rust crates and two
  TypeScript packages, the wasm boundary, the data paths from an `.xlsx` file to the page and
  back, where data is stored, the host doors used, and how it is built and tested.
- [`status.md`](status.md): what ships today, the limits of what ships, and what is not built.
- [`adr/`](adr/README.md): the decision records of this repository, 016 and 500–509.
- [`design/data-provider-consumer.md`](design/data-provider-consumer.md): how a sheet is
  filled from a dataset that another plugin publishes through the host.
- [`design/analysis-2026-10-04.md`](design/analysis-2026-10-04.md): the plugin measured
  against the everyday fundamentals of a spreadsheet, with the test, CI and performance state
  as found on 2026-10-04 and the records it corrected.

One document stays at the repo root: [`DECIMAL-SPIKE.md`](../DECIMAL-SPIKE.md), the measured
comparison of `f64` and exact decimal arithmetic behind [ADR 501](adr/501-f64-numbers.md).

## Decisions in other repositories that bind this one

These records live in other public paged-media repositories. The code here rests on each of
them. The last column says what the decision means for this plugin.

| ADR | Repository | Decision | What it means here |
|---|---|---|---|
| [010](https://github.com/paged-media/plugin-sdk/blob/main/docs/adr/010-raw-mutate-gate-capability-enforcement.md) | plugin-sdk | The raw-mutate gate and the capability enforcement line | The plugin writes with raw `document.mutate` operations under `document.write: "scoped"`. The `setPluginMetadata` operations in its batches must carry its own key, `x-paged:media.paged.sheet` (`packages/sheet-host-model/src/binding.ts`). |
| [012](https://github.com/paged-media/plugin-sdk/blob/main/docs/adr/012-k1-modal-session-undo-coalescing.md) | plugin-sdk | Modal sessions and the undo boundary | The `sheet` edit context supplies `isDirty`, `onUndo`, `onRedo`, `onCanUndo` and `onCanRedo` (`packages/sheet-bundle/src/activate.ts`). Keystrokes become one committed cell edit, and committed edits are journaled in the session. The step in which leaving the context rewrites the page content is not implemented here; see [`status.md`](status.md). |
| [017](https://github.com/paged-media/plugin-sdk/blob/main/docs/adr/017-importer-exporter-door-shape.md) | plugin-sdk | Importer and exporter door shape | `.xlsx` files are routed to this plugin's importer, which loads the bytes into its own session. The exporter returns the workbook as `.xlsx` bytes when the host asks. |
| [305](https://github.com/paged-media/plugin-sdk/blob/main/docs/adr/305-doors-always-present.md) | plugin-sdk | Every door is always present; `supports()` reports a missing backend | Eleven optional features are probed with `host.supports(...)`, each with a fallback: the panel's file input for the file picker, the blob store for container parts, memory for the blob store, no in-frame grid without the scene layer, an empty list without data providers, and no importer, exporter, object type, edit context or binding provider where the host has none. |
| [307](https://github.com/paged-media/plugin-sdk/blob/main/docs/adr/307-contract-as-peer-dependency.md) | plugin-sdk | Bundles take the contract packages as peer dependencies | `@paged-media/plugin-api` and `@paged-media/plugin-sdk` are peer dependencies of `@paged-media/sheet` (`packages/sheet-bundle/package.json`). |
| [308](https://github.com/paged-media/plugin-sdk/blob/main/docs/adr/308-plugin-wasm.md) | plugin-sdk | Plugin wasm is a declared capability, loaded by the bundle, under one size budget | The manifest declares one wasm module, `bin/sheet_js_bg.wasm`, at 8 MiB. `packages/sheet-bundle/src/engine.ts` loads it with the wasm-bindgen glue on first use. `scripts/build-wasm.sh` fails above 100 MB, so the two limits differ. |
| [310](https://github.com/paged-media/plugin-sdk/blob/main/docs/adr/310-one-write-door.md) | plugin-sdk | One write door: `document.mutate`, engine-owned history, failures as outcomes | Tables, cell text, chart paths, swatches and cell styles are all written through `host.document.mutate`. The code tests `outcome.applied` instead of catching, and puts the frame and its binding in one batch. |
| [311](https://github.com/paged-media/plugin-sdk/blob/main/docs/adr/311-plugin-state-under-own-id.md) | plugin-sdk | Plugin state lives only under the plugin's own id | The frame binding is kept under the metadata key `x-paged:media.paged.sheet`; the workbook is kept in the plugin's own container-part namespace and its own blob and storage keys. |
| [314](https://github.com/paged-media/plugin-sdk/blob/main/docs/adr/314-plugin-shape.md) | plugin-sdk | The plugin shape: semantics in Rust behind one wasm module, a logic-free shim, one published package | The `sheet-*` crates hold parsing, evaluation, formatting, XLSX and lowering; `sheet-js` is the one wasm module; `@paged-media/sheet` is the one published package. The TypeScript side holds the session, the panels and the translators from engine output to host operations. |
| [315](https://github.com/paged-media/plugin-sdk/blob/main/docs/adr/315-isolation-contract.md) | plugin-sdk | The isolation contract: a plugin depends only on the published contract | `scripts/check-contract-imports.mjs` runs before the tests and rejects any import other than the two contract packages, this repository's own packages and `react`. `deny.toml` denies crates from unknown registries and git sources. Data from another plugin arrives only through `host.dataProviders`. |
| [316](https://github.com/paged-media/plugin-sdk/blob/main/docs/adr/316-native-content-and-baking.md) | plugin-sdk | Plugin content is stored as valid native document content; baking is the fallback | A placed range is a native table in a text frame and a placed chart is native paths and text frames. The `sheetFrame` object type is declared with `bakedFallback: "rectangle"`. See [ADR 505](adr/505-native-table-and-edit-grid.md). |
| [317](https://github.com/paged-media/plugin-sdk/blob/main/docs/adr/317-registry-driven-dispatch.md) | plugin-sdk | Function and kernel dispatch is generated from a registry, with a coverage gate | `sheet-core/build.rs` and `sheet-fn/build.rs` generate the function table and the dispatch from `registry/functions/*.yaml`; `sheet-conformance/src/bin/coverage_gate.rs` fails when an implemented row names no test on disk. |
| [014](https://github.com/paged-media/plugin-data/blob/main/docs/adr/014-data-provider-arrow-seam.md) | plugin-data | The data-provider seam | This plugin is a consumer. The manifest declares `dataProviders.consume: ["dataset"]`, and the session calls `discover`, `get` and `onDidChange` on `host.dataProviders` (`packages/sheet-bundle/src/session.ts`). It reads the schema's field names and the column-major records of one snapshot. |
| [013](https://github.com/paged-media/core/blob/main/docs/adr/013-in-frame-scenelayer.md) | core | In-frame plugin rendering via `SceneLayer` | The in-frame grid is a scene layer of `fillPath`, `strokePath` and `text` items built by `gridSceneToSceneLayer` (`packages/sheet-host-model/src/grid.ts`) and submitted for one frame. |
| [118](https://github.com/paged-media/core/blob/main/docs/adr/118-paged-file-is-a-valid-idml-package.md) | core | A `.paged` file is a ZIP that stays a valid IDML package | The imported workbook is written as a part inside the `.paged` container (`packages/sheet-bundle/src/workbook-part.ts`), declared in the manifest as the part type `workbook` with format `xlsx`. See [ADR 506](adr/506-workbook-in-a-container-part.md). |
| [023](https://github.com/paged-media/editor/blob/main/docs/adr/023-shared-panels-binding-providers.md) | editor | Shared panels: the host owns the panel, plugins provide the values | Two binding providers are registered for the `sheet` context: one serves the workbook's colours to the host's Swatches panel and accepts `editSwatch`; one serves three character properties of the selected cells to the Character and Paragraph panels and accepts no writes. The provider types are copied locally in `packages/sheet-bundle/src/binding-provider/adr023-seam.ts`. |
| [024](https://github.com/paged-media/editor/blob/main/docs/adr/024-context-sensitivity-is-a-core-concept.md) | editor | Context-sensitivity is a core concept | The `sheet` edit context declares an empty tool set and one panel, and the copy and paste commands are offered only while a workbook is open (`packages/sheet-bundle/src/activate.ts`). |
